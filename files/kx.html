What is a Continuous Glucose Monitor (CGM)?

​​A CGM is a device used for monitoring blood glucose on a continual basis by people with either type 1 or type 2 diabetes.

 

Does Cigna cover Continuous Glucose Monitors?

​​Therapeutic:

  • Therapeutic CGMs are most commonly covered under the pharmacy benefit with a prior authorization
    • These components are dispensed by a pharmacy only
  • A select few therapeutic components may be allowed under the medical benefit, depending on what type of plan the customer has, integrated benefit status, and which component type is being requested.
    • ​These components are typically dispensed by a provider, DME Vendor, or pharmacy.
  • ​Cigna will always attempt to cover a therapeutic CGM under the pharmacy benefit first, when applicable.

Non-therapeutic: 

  • Non-therapeutic CGMs are excluded under the pharmacy benefit but may be covered under the medical benefit with a prior authorization.
    • ​​​These components are typically dispensed by a DME Vendor, pharmacy, or provider. 

 

Does each component need its own EOC/Case?

Medical

  • Only one EOC/case is needed for all components. Only one authorization with multiple line items for each component is needed in the medical management system.

Pharmacy:

  •  Only one case is needed for all components.

 

When working phones or online, how do I determine if the request is for a Therapeutic or Non-Therapeutic component?

​​​​Locate the drug name on the therapeutic and non-therapeutic tables below.

Example: If the request is for Dexcom G6, then the request is for a therapeutic component. If the request is for Dexcom G4, then the request is for a non-therapeutic component.  

 

When working faxes, how do I know if a request is for a Therapeutic or Non-Therapeutic NDC/Drug name?

The fax will need to be reviewed to determine if the provider is requesting a therapeutic or non-therapeutic drug. Use the brand name and component type to determine if the request is for a therapeutic or non-therapeutic NDC. Hint: If the request is sent on the 2022 Continuous Glucose Monitor fax form, the form is split into two sections, Therapeutic and Non-Therapeutic, with the different component names underneath.

Example: If the request is for Dexcom G6 - then ​the request is for a therapeutic component. If the request is for Dexcom G4, then the request is for a non-therapeutic component.

 

How do I handle a request for an Insulin Pump?

An infusion pump is a separate piece of equipment from a Continuous Glucose Monitor (CGM).  Some customers have only a CGM, others only an insulin pump, and some have both. An Insulin Pump request is considered Durable Medical Equipment. If a request is received for an Insulin Pump, follow the How do I handle a request for Durable Medical Equipment (DME)? article. 

 

Is a Durable Medical Equipment (DME) Vendor/Provider considered a third party?

DME providers are NOT considered a 3rd party they are allowed to submit prior authorization requests for CGM components, refer to the How do I handle calls from third parties? article.

​Examples of DME vendors/providers include, but are not limited to: Medtronic, MiniMed, US Med, and Edgepark

How do I know if precert is required for a CGM in TruCare?

When determining precert in TruCare, do not refer to the header (bolded in grey) to determine if precert is required. You must review the prescreen messaging to determine if an authorization is required under the medical benefit. If it is determined that precert is required, continue creating the authorization by checking the box beside the CGM line item and clicking Continue Authorization​.

Hint: ​When the prescreen results in "Continuous Glucose Monitor Products may be excluded under Medical Plan. Authorization required by pharmacy team, transfer to 74539 or 800-244-6224", precert is required under the medical benefit.

 

If there is an existing medical authorization on file for one of the old Therapeutic K Codes, do I need to update it to the new A or E codes or create a new review?

At this time, no updates will be required to the existing authorizations. If a provider bills using a new code and their authorization on file is for one of the previous codes, the claims will still pay. A new authorization request is not required.

​ 

Is there a Dexcom G7 Transmitter Component? 

No. There is not a Dexcom G7 Transmitter Component. The Dexcom G7 Sensor is fully disposable and combines the sensor and transmitter into one piece, eliminating the need for a separate transmitter component. 

 

When working phones or online, how do I handle the request if the provider asks for a different HCPC code than listed below?

​​​​Advise the caller that the HCPC codes listed in the table below are the only codes associated with the listed component and ask which component and associated code they would like the request to be built for. We cannot create a request for a code that is not associated with the component.

Example: If the request is for Dexcom G7 Sensor, then the request must be built with A4239. We cannot create a request for A9278 for the Dexcom G7 Sensor.
